## Переходы
- Расстояние между якорями большое → сжатый перелёт: город рассыпается в точки, камера идёт быстро, собирает город у цели (1.2–1.8 с). Без склеек.
- Сплайн Catmull-Rom (0.5), параметризация по длине дуги. Магнитность ±3% по P (скролл ×0.33–0.5). Угловая скорость ≤25°/с. Коллизии по сетке коридора, при риске поднимаем высоту.
- Порядок остановок по P фиксирован; **порядок якорей в пространстве** (Русский мост → Золотой → центр → коса → отель) проверяется на M1 по `anchors-preview.png`: если путь самопересекается или слишком длинен, меняем маршрут, а не склеиваем.
