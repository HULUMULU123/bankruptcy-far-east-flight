# Банкротство Дальний Восток — демо-макет первой страницы

Один непрерывный пролёт над Владивостоком: информация живёт внутри сцены (мост, крыши, коса, отель).
Данные города: © участники OpenStreetMap, рельеф Copernicus DEM GLO-30. Тексты, фото спикеров и контакты — с https://bankrufeast.ru/.

```bash
npm install
npm run dev     # http://127.0.0.1:5176
npm run build
```
Данные пересобираются скриптами в `scripts/` (Python 3 + Node/Playwright), см. `package.json` → `data`.
Демо: логотип и материалы принадлежат правообладателям; репозиторий — рабочий макет, не продукт.
